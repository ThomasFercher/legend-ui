Guidance for Claude Code when working on this branch (`rewrite`).

## What this is

The **full rewrite** of Nomo UI Kit as a Dart workspace. `main` is the frozen legacy kit — never merge from it. `legacy-docs` holds the complete legacy documentation and the accepted design RFC; a working copy of the RFC is [docs/DESIGN.md](docs/DESIGN.md). **Read DESIGN.md before designing or implementing anything** — the architecture decisions there are settled.

packages/nomo_gen/       # standalone codegen CLI (pure Dart) — decided over build_runner

## Settled architecture rules (from DESIGN.md — do not relitigate casually)

1. **Component themes are declared with decorators on the widget** (`@NomoThemeable` / `@Themed`); plumbing is generated by `nomo_gen`. Generated files are committed; CI verifies freshness via `nomo_gen --check`.
2. **All `@Themed` constructor params are nullable with null defaults** — the generator enforces this. Never give a themed param a non-null default (legacy bug: it made theme values unreachable).
3. **Four-level resolution**, nearest wins: constructor param → `…ThemeOverride` subtree widget → `NomoThemeData.components[Type]` → token-derived annotation defaults (these ARE the kit defaults; see DESIGN §9.9).
4. **`NomoThemeData` is an open Type-keyed registry** — consumers register their own generated component themes in the same map. Never introduce a closed/generated aggregate registry or naming conventions.
5. **Generation is one-file-in/one-file-out** — no cross-file or whole-project analysis in the generator, ever.
6. **Responsiveness ≠ theming**: breakpoints via `NomoBreakpoints`; theme switches swap `NomoTokens` (lerp tokens once, not per-component classes).
7. Components compose the five primitives (surface, interactive, overlay engine, text core, field core); no Material `Scaffold`/`InkWell` dependencies; no vendored forks of Flutter/third-party widgets.
8. Quality gates are non-negotiable: tests with every feature (generator changes need golden tests), very_good_analysis clean, no public-API typos.
